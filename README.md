# 慢島劇團 Slow Island Theatre 官方網站

慢島劇團（Slow Island Theatre）創立於 2008 年台灣桃園，致力以藝術舒緩現代生活的急促步調，深耕在地田調、場域戲劇與多元感官劇場。
